# `docs/execucao-pendencias/relatorios/` — relatórios de saída

Cada branch de execução escreve aqui `E<N>.md` ao terminar, e a integração escreve `INTEGRACAO.md`.

Todo relatório traz: o que foi feito, os testes novos, o que foi conferido e como, os riscos
registrados, os passos manuais com valor literal e completo, e termina na linha
`E<N> pronta para integração — <hash>`. A integração só começa quando os sete (E1 a E7) existem.

Cada branch cria só o próprio arquivo, então não há conflito entre elas nesta pasta.
